# Phase 8 configuration

I use these configuration files to keep benchmark assumptions explicit and editable.

- `benchmark_parameters.csv` controls the tolerance band and minimum city market size.
- `external_benchmark_inputs.csv` is optional. I only populate it when I have a directly comparable external benchmark with a documented definition, period, population, unit, and source.

The Phase 8 notebooks run using internal portfolio and peer-market benchmarks even when the external template remains blank.
